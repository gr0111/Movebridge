기존 기타 운동 348건에는 고유 제목 203개가 있었다. 20개 제목이 반복되며 해당 행은 165건이다. 테니스 제목 7개가 각각 36·24·24·18·14·14·9회 나타났고, 나머지 반복 제목 13개는 각각 2회 나타났다. 정확한 제목별 빈도는 CSV의 `이전 기타 운동 동일 제목 빈도`에서 확인할 수 있다.

- 방학특강 `305`의 원본 제목은 `실내승마`, `312`는 `탁구`를 명시한다. 골프나 당구로 표기된 강좌는 제목이 `특강`으로 시작해도 원본 종목으로 집계한다.
- 기존 확인 필요 6건 중 `307`과 `309`는 이전에 승인된 `방특 배민` 표기 해석을 사용해 배드민턴을 추정했다. 공식 약어 해석은 확인이 필요하며, 표와 코드에서 추정 2건을 구분한다.
- `2073`과 `2077`의 바디슬림, `2086`의 바디 트레이닝은 구체적인 운동을 확인하기 어렵다. `헬스등록필수`는 등록 조건이다. `2137`은 원본 종목이 공란이고 제목이 `자유이용`이다. 네 건 모두 분류 확인 필요이며, `2137`의 기본 검색 제외 처리를 유지한다.
- CP949 원본의 2026년 수강월에 해당하는 400건을 `일련번호`로 첨부 샘플과 대조했다. 13개 원본 필드 중 수강금액만 정수와 소수점 한 자리 표기 차이가 있었으며 금액의 수치는 같다.

## 기관 영상 56건

- 기존 운동 외 콘텐츠는 `254` 가요교실, `228` 온라인 수강신청 방법, `219` 실시간 라이브 접수 시작 안내였다. 새 비교 집계에는 `319` 점핑·라인 강좌 접수와 `221` 러닝크루 접수도 같은 기준으로 포함한다. `225`의 K-POP 응원 홍보 제목도 운동 외로 집계한다. 행사나 예고 영상에 실제 종목명이 명시되면 그 종목을 주제로 집계할 수 있다. 콘텐츠의 강습 여부는 별도 정보다.
- `304`는 명시적으로 라인댄스라고 적힌 `302`와 제목 문구가 유사하며 종목이 확인되지 않는다. `291`의 `오픈 턴`, `290`의 `스타트`는 수영 표기가 있는 영상과 목록에 인접해 있으며 제목 자체에는 종목명이 없다. `256`, `240`, `235`, `232`는 제목만으로 운동 유형을 확정하기 어렵다. 일곱 건 모두 분류 확인 필요로 유지한다.
- `242`의 `골프 비거리 향상을 위한 근력운동`은 제목이 명시하는 실제 활동과 첨부 관심분야에 따라 근력운동으로 집계한다. `323`의 여러 영법은 수영 한 건으로 집계한다. 기관 영상 56건의 원본 제목·등록일·조회수·링크를 CP949 원본과 대조했다.
