## 2. 2,137행과 400행의 관계

수강월을 ISO 날짜로 검증한 다음 연도가 2026년인 행을 추렸다. 2026년 1월 384행, 2월 14행, 4월 1행, 6월 1행이다. 이전 기록은 1,737행, 2026년 이후와 수강월 파싱 실패는 각각 0행이다. 전체 연도별 집계는 1990년 24행, 2013년 1행, 2014년 8행, 2015년 3행, 2016년 8행, 2017년 1행, 2018년 2행, 2020년 7행, 2022년 611행, 2023년 86행, 2024년 514행, 2025년 472행, 2026년 400행이다. 원본과 서비스 CSV는 일련번호·강좌일련번호·강좌서브일련번호를 비롯해 12개 필드의 문자열이 일치한다. 400행의 금액은 `70000`과 `70000.0`처럼 표현이 달라 13열 전체 문자열의 완전 일치는 0행이며, Decimal 비교 결과 금액의 차이는 0행이다. 분석 근거는 제목의 동일성이 아닌 식별번호와 공통 필드 비교다. 식별번호 조합의 공식 키 정의는 확인되지 않았다. [행별 대응](results_2026-11-25/record_matching.csv) · [추출 범위 밖 기록](results_2026-11-25/unmatched_records.csv)

이전 전처리 산출물도 비교했다. 전체 변환본은 2,137행, 2026년 변환본은 400행으로 해당 원본 행과 순서까지 일치하고, 두 변환본 모두 의미상 필드 차이가 0행이었다. 외부 폴더의 검색 CSV와 저장소 검색 CSV의 SHA-256도 일치했다. 검색 CSV의 파생 컬럼 12개를 원본 값에서 다시 계산해 불일치 0건을 확인했다. 수강월 추출 과정에서 별도 결측 삭제, 중복 제거 또는 다른 출처 추가가 있었다는 결과상의 증거는 없다. 최초 CSV 생성 스크립트는 조사한 저장소 이력과 전처리 자료에서 찾지 못했다. 따라서 최초 실행 명령은 확인되지 않았으며, 판정은 실제 산출물과 행 대조에 근거한다.

Git `c7c3b61` 시점에 추적된 `sample-data.ts`의 강좌 배열은 서비스 CSV 400행 × 25열과 순서·값까지 일치한다. Vite 서비스는 이 배열을 로딩해 검색용 객체로 매핑하고, 별도 분류 개선 커밋 `924bc8b`에서 분석용 상위 분야와 세부 종목을 도입했다. ## 8. 개발팀 전달 항목

1. 일반 강좌 검색은 현재 2026년 399행을 유지한다. 수강월이 과거인 1,737행은 기록·품질·종목 분포 분석의 별도 범위로 사용한다. 행 수를 신청자 수나 수요로 해석할 근거는 없다.
2. 원본 종목, 표준 세부 종목, 관심 분야, 분류 상태와 근거를 함께 보존한다. 오래된 추가 종목을 자동 분류에 적용하기 전에 원본 종목과 제목이 충돌하거나 복합 프로그램인 행을 검토한다. 1945번, `방특 배민` 2건, 1990년 24건과 괄호 요일 의미는 제공기관 확인 대상으로 기록한다.
3. 실제 운영·신청 안내는 기관의 최신 센터별 운영 상태와 고유 신청 주소를 확인한 뒤 제공한다. 요일 괄호, 장시간 범위, 제목과 시간 필드 차이를 시간표에 표시할 때 원본과 확인 상태를 함께 제공한다.
4. 기관 영상과 외부 YouTube는 출처와 집계를 유지한다. 세부 종목을 바탕으로 연관 자료를 보여줄 수 있으며, 개별 강좌와 영상의 공통 ID 또는 기관 연결 근거가 확보되면 동일 프로그램 관계를 검토한다. 시설개방 데이터는 지역별 시설 탐색에 별도 사용한다.

## 9. 재현성 및 무결성

분석 브랜치는 기존 프로젝트 경로에서 전환했다. 기준 서비스 커밋과 이전 분류 커밋은 [종합 지표](results_2026-11-25/summary.json)에 기록했다. 실행은 Python 3.9.6 표준 라이브러리, Node.js v22.19.0을 사용했다. 입력 CSV는 바이트 해시와 엄격한 CSV 파싱을 적용하고, 날짜는 날짜 객체와 ISO 형태로 검증했다. `9999-12-31`을 결측으로 바꾸지 않았다. 공백·유니코드 NFC 및 금액의 Decimal 비교는 별도 비교 규칙에만 적용했다. 중복 계산은 원본 값의 그룹으로 세고 그룹 수·포함 행 수·초과 행 수를 구분했다. 비율 분자는 해당 행 수, 분모는 각 표의 집계 대상 전체 행 수다.

입력 CSV 13개와 조사한 서비스 파일의 분석 전후 SHA-256은 일치한다. 서비스 소스, 기존 가공 데이터, DB 설정, CI와 Maestro는 서비스 기준 커밋과 일치한다. 공개 산출물에는 원본을 찾을 수 있는 파일명과 해시를 제공하며, 로컬 절대경로와 강좌명에 포함된 강사 이름은 공개 범위에서 제외했다. [원본 확보 및 실행 방법](README.md)
