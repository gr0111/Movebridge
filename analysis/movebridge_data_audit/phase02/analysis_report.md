## 2. 세부 종목 연계의 확대와 남은 공백

일반 검색 399건은 근거 확인 394건, 추정 2건, 확인 필요 3건이다. 분모는 근거 확인 394건에 등장하는 **고유 세부 종목 19개**와 **상위 분야 10개**다. 상위 분야와 표준 세부 종목이 모두 같으면 정확 일치다. 상위 분야만 같으면 같은 분야 자료로 집계했다. 동일 교육과정 여부는 공통 ID나 공식 연결 근거가 있어야 확인할 수 있다.

기관 영상 56건은 분포에 모두 포함했다. 연계 계산은 종목·주제 근거가 있는 40건을 사용했다. 확인 필요 7건, 운동 외 6건, 별도로 종목이 분류된 행사·예고 3건을 연계에서 제외했다. 이 40건의 강습 내용과 열람 가능성은 별도 확인 사항이다. 외부는 검증 CSV 131건을 사용했다. 명칭이 같은 운동을 가리키는 `줌바`를 `줌바댄스`로 통합했고, `로드사이클`과 `스피닝`, `헬스`와 `헬스장 루틴`은 각각 같은 분야까지만 연결했다. ## 3. 운동 입문 콘텐츠의 탐색 공백

제목은 `입문·처음·초급·기초`와 영문 독립 단어 `Beginner`를 조사해 행당 한 번 집계했다. 기존 앱의 제목 정규식과 CSV의 표본 `추천운동경험`은 각각 별도 지표로 저장했다. 전체 강좌 제목에서는 96/2,137건, 2026년 강좌에서는 29/400건이고, 검색 강좌에서도 29/399건이다.

기관 영상은 제목 표현 1/56건(1.79%)이다. `Beginner`가 있는 304번은 종목 확인 필요라 연계 대상의 제목 표현은 0/40건이다. 기관 자료의 표본 경험 수준은 미제공이다. 외부 영상의 제목 표현은 7/131건(5.34%)이며 기존 앱 규칙으로는 4/131건이다. 표본 추천운동경험은 입문·기초 44/131건(33.59%), 중급 32건, 고급 2건, 여러 수준 혼합 7건, 판단 보류 46건이다. 두 지표에 함께 해당하는 외부 영상은 2/131건이다. 줌바댄스에 추가로 연계된 8건의 경험 수준은 전부 판단 보류다. 같은 종목의 표본 입문·기초 영상이 있는 강좌 종목은 요가·필라테스 2/19종목이고 해당 강좌 제목에는 입문 표현이 없었다. 탁구·당구는 입문 표현 강좌가 있으나 같은 분야 영상까지 공백이다. 로드사이클은 같은 분야 자료까지, 라인댄스는 같은 종목 영상까지 이어지며 둘 다 정확 일치한 입문·기초 표본은 없다. 배드민턴·테니스·농구·검도·골프·실내승마 6/19종목은 강좌 제목과 정확 일치·같은 분야 영상에서 입문 관련 표현이나 입문·기초 표본을 찾지 못했다. 실제 난이도와 참여 가능성 검증은 별도다.

## 4. 대시보드와 공모전 활용 방향

1. **전체 원본을 기록 분석에 활용한다.** 2,137건 전체와 2026년 400건을 병렬로 비교하고 기본 검색 399건을 별도로 표시한다. 2022년 테니스 기록 집중처럼 연도별 구성이 다른 이유를 확인할 수 있도록 원본 종목과 분류 근거를 함께 보여준다.
2. **온라인·오프라인 연결 효과를 종목 단위로 보여준다.** 외부 영상 131건 추가 후 같은 종목 연결이 3→5종목으로 늘었고, 연결 가능한 상위 분야는 4→4개다. 요가·줌바댄스가 추가된 효과와 여전히 비어 있는 종목을 함께 보여준다. 공공기관 영상 수는 56건이다.
3. **입문자에게 탐색 근거를 표시한다.** 같은 종목, 같은 분야, 종목 추정 여부, 표본 입문·기초, 제목의 입문 표현을 독립된 정보로 안내한다. 강좌에는 기록 기준과 운영·모집 확인 상태를 표시한다.

현재 일반 검색의 기타 운동 350건은 분석상 라켓 스포츠 171, 골프 81, 당구 70, 승마 17, 구기 6, 무도 5건이다. 제목에 일시중지가 있는 7건은 모두 실내승마로 현재 일반 검색과 로드맵 후보에 들어 있다. 7건을 전부 북마크한 조건에서 기존 시간표 모델은 19개 요일 슬롯을 만든다. 제목과 수강시간이 다른 102·134·138번은 현행 화면의 충돌 함수도 같은 결과를 냈다. 2026년 강좌 중 특수 종료일은 380/400건, 11월 27일 기준 일반 종료일 경과는 20/400건이다. 현재 운영 여부는 확인하지 않았다. ## 재현 방법

저장소 루트에서 Python 3.9.6과 Node.js 22.19.0으로 실행했다. Phase 2는 저장소의 기존 강좌·영상 파일과 Phase 1의 요약·분류·품질 결과를 읽는다. 입력을 보존한 채 기준 커밋의 서비스 분류 함수를 실행한다. 공개 CSV는 UTF-8 BOM이며, 제목에 포함된 강사 이름은 출력 단계에서 마스킹한다. 분야와 세부 종목 표 각각에서 400·399·56·131건이 재현된다. 재실행에는 새 출력 경로를 지정한다. [원본 출처 및 확보 방법](../phase01/README.md#원본-출처와-확보-방법)

```sh
python3 -B analysis/movebridge_data_audit/phase02/analyze.py \
  --as-of 2026-11-27 --out ./phase02-reproduction
```
