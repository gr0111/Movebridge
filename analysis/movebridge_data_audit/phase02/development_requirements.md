# MOVEBRIDGE 개발 전달 요구사항

작성일 2026년 11월 27일 KST · 현행 서비스 기준 `3a6316a` · [Phase 2 분석 보고서](analysis_report.md)

## 1. 검색 종목 선택과 분석 분류 연결

**현황.** `classifyCourse()`에서 분석 분야를 기존 관심 분야 목록으로 접는다. 라켓 스포츠 171건, 골프 81건, 당구 70건, 승마 17건, 구기 6건, 무도·격투 5건이 기타 운동 350건으로 모인다. 여기에는 배드민턴 추정 2건이 포함된다. [현행 변환 코드](../../../Frontend/src/data/discovery.ts#L64)

**요구사항.** 검색 선택지에 분석용 상위 분야와 표준 세부 종목을 제공한다. 기존 기타 운동은 위 6개 분야를 포괄하는 선택으로 호환한다. 분석과 검색에 공통 표준 ID 또는 버전 관리된 대응표를 사용하며, 원본 종목과 콘텐츠 ID를 보존한다. 종목 추정·분류 확인 필요를 검색 카드에서 표시한다. 상위 분야 변경 시 호환되는 세부 선택만 유지하고 첫 9건부터 표시한다.

**인수 기준.** 필터 미적용 검색은 399건이며 2137번은 분석 400건 범위에서 조회된다. 기존 기타 운동과 세분화한 6개 분야의 강좌 ID 합집합이 350건으로 같다. 추정 2건에는 근거 표시가 있다. 필터·정렬, 9→30→51→72 누적 보기, 북마크와 시간표 회귀 검증이 통과한다.

## 2. 원문의 일시중지 표기와 추천·시간표

**현황.** 실내승마 7건(2007·2019·2031·2040·2043·2046·2049번)에 일시중지 문구가 있다. 카드의 안내 태그와 달리 현행 로드맵 후보와 자동 시간표에서는 해당 상태가 반영되지 않는다. 7건을 모두 북마크한 경우 19개 요일 슬롯을 확인했다. [카드 안내](../../../Frontend/src/data/course-display.ts#L71) · [로드맵 규칙](../../../Frontend/src/features/onboarding/roadmap.ts#L43) · [시간표 모델](../../../Frontend/src/features/workout-planner/planner-model.ts#L105)

**요구사항.** 원본의 일시중지 표기와 현재 운영 확인 상태를 별도 속성으로 둔다. 일시중지 표기 행은 기본 로드맵과 북마크의 자동 주간 배치에서 제외하고, 검색·저장 목록·상세에서 원문과 확인 상태를 안내한다. 사용자 북마크 키와 개인 일정·완료 기록을 보존한다. 공식 재개 정보가 확보되면 확인 날짜와 URL을 붙여 추천과 자동 배치의 재개를 검토한다.

**인수 기준.** 현재 데이터로 7건 모두 일반 검색과 기존 저장 목록에서 보인다. 기본 로드맵과 자동 시간표에는 해당 7건의 슬롯이 없다. 개인 일정과 완료 기록에는 변화가 없고, 상세는 일시중지 원문과 운영 미확인을 함께 표시한다.

## 3. 운영·모집이 확인되지 않은 강좌

**현황.** 2026년 400건 중 특수 종료일 380건, 분석일 기준 일반 종료일 경과 20건이다. 운영·모집·잔여석은 별도 확인이 필요하다. [종료일 지표](summary.json)

**요구사항.** 카드와 상세에 기본적으로 “공개 강좌 기록 · 현재 운영·모집 미확인”을 표시한다. 수강월과 기록상 종료 상태를 따로 안내한다. 시간표에서 운영 근거가 없는 강좌는 “공개 강좌 참고 일정”으로 표시하고 개인 일정과 구분한다. 기관의 최신 자료에서 운영·모집을 확인하면 확인 날짜, 근거 URL과 함께 표시한다. 기관 공통 안내와 강좌별 공식 신청 URL에 각각 정확한 레이블을 사용한다.

**인수 기준.** 특수 종료일·경과 날짜·일시중지 조합에서도 원본 근거만 있으면 운영·모집은 미확인으로 표시된다. 확인 날짜와 공식 근거가 없는 상태값으로 모집 중 또는 신청 가능 배지가 생성되지 않는다. 공통 기관 안내는 안내 링크의 역할만 한다.

## 4. 제목과 수강시간의 불일치

**현황.** 102·134번은 제목 17~20시와 시간 필드 17:00–21:00이 다르고, 138번의 시간 필드는 17:00–19:00이다. 기존 상세는 두 표기와 시간 필드 우선을 안내한다. [상세 안내 코드](../../../Frontend/src/App.tsx#L1309)

**요구사항.** 검색 조건 계산과 카드의 공개 시간은 구조화된 수강시간을 사용한다. 불일치 플래그를 카드와 상세에서 공유하고, 상세는 원문 제목 시간과 수강시간을 병렬 표시한다. 북마크로부터 반복 일정을 자동 배치하는 동작을 보류하고 확인한 시각으로 개인 일정을 따로 추가할 수 있게 한다. 공식 확인값을 도입할 때 원본 두 값과 확인 날짜·근거를 함께 보존한다.

**인수 기준.** 102·134·138번은 일반 검색에서 조회되고 카드와 상세에서 “시간 확인 필요”가 보인다. 구조화된 필드로 검색 일치가 계산된다. 확인 전에 북마크하면 정상 반복 일정이 생성되지 않는다.

## 5. 같은 종목과 같은 분야의 영상 연계

**요구사항.** 상위 분야와 표준 세부 종목이 모두 같으면 “같은 종목”, 상위 분야만 같으면 “같은 분야”로 표시한다. 같은 종목 목록과 분야 대안 목록을 분리해 반환한다. 명칭 동치 매핑은 근거와 함께 관리한다. 추정 근거는 표시하고, 분류 확인 필요·운동 외·행사·접수·홍보는 운동 연계 후보에서 제외한다. 동일 교육과정을 표시하려면 공식 공통 ID 또는 직접 연결 근거가 있어야 한다.

**인수 기준.** 근거가 확인된 검색 19종목에서 기관만 필라테스·헬스·라인댄스 3종목, 외부를 더하면 요가·줌바댄스를 포함한 5종목이 연결된다. 로드사이클과 스피닝은 같은 분야로만 나타난다. 배드민턴 추정 2건에는 추정 근거와 영상 공백을 안내한다. 줌바↔줌바댄스 매핑 전후 수치를 재현할 수 있다. [연계표](content_coverage.csv)

## 6. 영상 출처와 입문 판단 근거

**요구사항.** 목록·상세·필터·분석에서 “공공기관 공개 영상”과 “외부 YouTube”를 구분한다. 기관 영상은 기관과 공식 URL, 외부 영상은 채널과 원본 URL을 표시한다. “제목에 입문 표현”과 “표본 추천운동경험”은 독립된 필드로 제공한다. 판단 보류 상태를 유지하며 기관 영상의 제목 단서, 외부 영상의 검증 구간 및 분류 확인 상태를 확인할 수 있게 한다.

**인수 기준.** 기관 56건, 외부 131건, 전체 영상 187건이 재현되고 공공데이터 영상 집계는 기관 56건이다. 외부 제목 표현 7건, 표본 입문·기초 44건, 두 조건 모두인 2건이 별도로 집계된다. 기관 304번의 제목 표현과 분류 확인 필요가 함께 표시된다. 외부 줌바 8건의 경험 수준은 판단 보류다.

## 7. 전체 원본 분석 대시보드

**요구사항.** 전체 2,137건과 2026년 400건을 비교하는 분석 범위를 제공하고 일반 검색 대상 399건은 별도 표기한다. 연도·상위 분야·세부 종목·분류 상태별 필터와 표를 제공한다. 원본 종목과 분류 근거를 조회할 수 있게 하고, 표시 건수와 구성비의 분모를 안내한다. 과거 전용 원본 종목 57건, 일반 확인 필요 24건, 약어 추정 4건을 각각 집계한다. 1990년 24건에는 날짜 의미의 확인 상태를 표시한다. 과거 강좌는 분석 전용 산출물로 제공한다.

**인수 기준.** 기본 합계가 전체/2026년/2026년 이전 각각 2,137/400/1,737이며, 라켓 스포츠 1,330/171, 골프 227/81, 당구 259/70이 재현된다. 분류 상태 필터를 적용하면 화면의 분모도 함께 갱신된다. 축과 표에는 공개 강좌 기록 행 단위, 출처, 기준일이 표시되고 키보드로 데이터 표를 탐색할 수 있다. 일반 검색·북마크·시간표가 과거 분석 범위 변경의 영향을 받지 않는다.

## 구현 순서

일시중지·시간 충돌의 자동 일정 배치, 운영 상태, 영상 출처·입문 근거 표시를 우선 개선한다. 다음으로 검색 분류 확장, 세부 종목 연계, 과거 원본 대시보드를 구현한다. 검색 대상 수와 콘텐츠 ID, 북마크·개인 일정·완료 기록을 각 배포의 공통 인수 조건으로 삼는다.
